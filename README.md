
# G+9 RC Residential Building — ETABS

## Project Overview

This project presents the structural modeling, analysis and selected reinforced concrete design checks of a hypothetical G+9 residential building using ETABS.

The project was developed for educational purposes and to demonstrate structural engineering skills in a technical portfolio. It illustrates the use of structural analysis software to investigate building behavior under gravity and lateral loading.

## Project Objectives

- Develop a three-dimensional reinforced concrete building model in ETABS.
- Define structural materials, section properties, load patterns and load combinations.
- Perform linear static, modal and response-spectrum analyses.
- Review storey drift, modal participating mass ratios and base reactions.
- Review selected reinforced concrete beam and column design results.
- Document the modeling process and analysis outputs for a structural engineering portfolio.

## Software

- **ETABS** — Structural modeling, analysis, and concrete frame design review.
- **Microsoft Word** — Project report preparation.
- **Microsoft Excel** — Organization and review of exported analysis and design results.

## Structural Analysis

The project includes the following analysis procedures:

- Linear static analysis
- Modal analysis using the Eigen vector method
- Response-spectrum analysis in the global X and Y directions
- Review of storey drift and horizontal base reactions
- Review of selected concrete frame design outputs

## Limitations

This is a hypothetical academic portfolio project, not a commissioned building design.

The analysis results depend on the model geometry, material and section properties, loading assumptions, boundary conditions and software settings. The seismic parameters, response-spectrum scaling, load combinations, member design results and applicable acceptance criteria require appropriate verification.

The project has not been established as fully compliant with the Bangladesh National Building Code (BNBC) 2020. The model and results must not be used as construction documents or as confirmation of structural safety for an actual building.
